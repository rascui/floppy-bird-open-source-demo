## Contribution Workflow

### 1. Fork & Clone
Fork this repository to your GitHub account, then clone your fork locally:
```bash
git clone https://github.com/[YOUR USERNAME]/floppy-bird-open-source-demo.git
cd floppy-bird-open-source-demo
```

### 2. Make changes and commit + push
push changes to your forked repo

### 3. Make pull requests with a formal title and description
Fill the google forms and make pull request

### 4. Get certificate
You will be notified soon
